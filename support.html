TesterUtils Support

Help with installation, features, licensing, and problems using TesterUtils.

Before reporting an issue

Please confirm that you are running the latest Microsoft Store version of TesterUtils and restart the app once if the problem is temporary.

What to include

When reporting a problem, include the TesterUtils version, Windows version, the feature you were using, steps to reproduce the issue, and any error message shown. Please remove passwords, tokens, customer information, or other sensitive data from screenshots and examples.

TesterUtils Pro

TesterUtils Pro is a one-time lifetime upgrade distributed through Microsoft Store. Purchase and entitlement handling uses Microsoft Store services. If an entitlement does not appear immediately, restart TesterUtils after confirming that Microsoft Store is signed in with the account that owns the purchase.
